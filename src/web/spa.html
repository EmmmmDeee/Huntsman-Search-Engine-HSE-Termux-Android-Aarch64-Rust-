Huntsman Search Engine v?

Huntsman Search Engine (HSE) is an all-source OSINT / GEOINT / NETINT reconnaissance engine. Pure Rust and keyless-first, it runs entirely on Termux on Android aarch64 (no root): one binary, rustls only, no native dependencies, bundled SQLite, and this console embedded in it.

The console follows SpiderFoot 4.0's look and workflow (New Scan, Scans, Settings), rebuilt from scratch with no vendored UI framework.

You are running version v?.

Source code and documentation are on GitHub.

API keys are sensitive. Set them in $HOME/.huntsman.env (chmod 0600) or on the Settings page (editable by default, loopback only; lock it with hse serve --no-key-write). Never paste keys into chat, screenshots, or shared documents.
