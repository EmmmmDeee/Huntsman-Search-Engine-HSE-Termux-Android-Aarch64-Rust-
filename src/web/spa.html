Huntsman Search Engine

Huntsman Search Engine (HSE) is an all-source OSINT / GEOINT / NETINT reconnaissance engine in the GhostSec tradition — SpiderFoot-inspired breadth without the daemon or the footprint. Pure-Rust and keyless-first, it runs entirely on Termux on Android aarch64 (no root): single binary, rustls-only, no native dependencies, bundled SQLite, embedded SPA.

You are running version v?.

The scan workflow follows the same mental model as SpiderFoot for operator familiarity, on a from-scratch, mobile-first console design (no vendored UI framework — see the About-page source for details). Source code on GitHub.

⚠️ API keys are sensitive. Set them via $HOME/.huntsman.env (chmod 0600) or on the Settings page (editable by default, loopback only; lock down with hse serve --no-key-write). Never paste keys into chat, screenshots, or shared documents.
