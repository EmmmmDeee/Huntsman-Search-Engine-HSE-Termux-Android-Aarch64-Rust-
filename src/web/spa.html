Huntsman Search Engine

Huntsman Search Engine (HSE) is a pure-Rust OSINT / GEOINT prototype designed to run on Termux on Android aarch64 (no root). Single binary, rustls-only, no native dependencies, bundled SQLite, embedded SPA.

You are running version v?.

UI patterns and visual identity intentionally mirror SpiderFoot for operator familiarity. Source code on GitHub.

⚠️ API keys are sensitive. Set them via $HOME/.huntsman.env (chmod 0600) or on the Settings page (when hse serve --allow-key-write is enabled, loopback only). Never paste keys into chat, screenshots, or shared documents.
