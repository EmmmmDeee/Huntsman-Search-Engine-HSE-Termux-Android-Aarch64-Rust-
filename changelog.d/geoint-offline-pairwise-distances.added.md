- Offline analysis now includes exact, bounded great-circle distance measurements between explicitly supplied coordinate seeds, exposed through the existing `/api/analyze` JSON response and mobile Web UI. Up to 16 coordinate seeds produce at most 120 sorted pairs; an overflow flag makes the cap visible. Antimeridian separation is handled by the existing spherical distance model. No external source is queried and no identity, co-presence or independent-corroboration claim is inferred.
