- The corroboration gap (AU-063) no longer says that one identity pathway is the only connection between two entities. The pathway count takes the strongest path first and never reconsiders it, so it can find one pathway where two disjoint ones exist: over `s-p`, `p-w`, `w-t`, `p-q`, `q-t`, `s-r` and `r-w`, all alias relations of one strength, `disjoint_pathways("s", "t", ...)` returns 1 in that order and 2 with the list reversed, and `s-p-q-t` and `s-r-w-t` are two disjoint pathways. A pair whose count finds one pathway reads "one identity pathway found connects the pair; a second may exist that the search did not take", and the pairs that one shared handle carries read "5 pairs among these 4 entities each have one identity pathway found, which rests on a shared handle". Which pairs raise a gap, its severity and the entities it names are unchanged. The count itself is unchanged, and so is its order dependence, which is a follow-up.
