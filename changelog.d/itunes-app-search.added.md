- Add a keyless `itunes KEYWORD` lookup: a search of the Apple App Store for one keyword, Spiderfoot's `apple_itunes` leg, over Apple's public iTunes Search API. Each app it returns becomes a candidate `Url` entity for its App Store page, with its name, seller, bundle identifier, genre and release date kept in full as evidence. A keyword match is a candidate to review, never a confirmed link to the keyword's owner, so its confidence is deliberately modest and every result names the search term that produced it. A search with no matches is a clean negative, and a refusal or a body that is not a result set is reported as a failure, not a zero.
