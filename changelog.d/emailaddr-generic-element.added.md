- The role and contact email addresses a whois record publishes — the abuse and registrar contacts from the keyless `netlas` lookup, and the abuse contact from the keyless `isc` lookup — are now surfaced as `EMAILADDR_GENERIC` elements in the Spiderfoot element view, giving that catalogued element type its first producer. The lookups already record these on the IP or domain they describe; before this they survived only inside that entity's raw evidence and never appeared as typed elements, so they were absent from Browse by type, the per-type summary, exports and correlations. Each element is gated on the genuine source that writes the attribute and is emitted only when the value parses as a single address, so a same-named field from elsewhere or a malformed value cannot forge one. No extra network request is made.
