- `username john.doe` (or any handle joined by `.`, `_` or `-`) no longer tags the operator's own seed as a derived candidate. The variants that differ only by separators (`john-doe`, `john_doe`, `johndoe`) share the seed's identity, so merging folded them into the seed. The seed then read `seed,derived,variant,candidate`, carried the variants' inferred evidence, and dropped out of confirmed-only correlations and cross-scan bridges. Those variants are now not emitted.
- A username variant that is a placeholder, such as `username` from `username1990`, `example` from `the_real_example` or `redacted` from `redacted_99`, is no longer emitted as a candidate entity.
- `scan --input-file` ignores a UTF-8 byte-order mark at the start of the file. A file saved "UTF-8 with BOM" kept the invisible mark on its first line, so the first seed was refused as not canonical (exit 65), or a first-line comment was scanned as a seed.
- A reviewed "missing" difference in a legacy differential stays accepted when the port later produces a partial value or another source's copy of that record. It used to turn into a reported truncation or misattribution.
- A capability that names a benchmark must have that benchmark's receipt. The readiness report printed a capability's benchmark text in its Benchmark column without any receipt check, against its own receipt-only rule. The shipped manifests name none, so the generated report is unchanged.
- `domain-lifecycle` reports a content-digest scope that is not an http(s) URL as invalid input ("content digest needs exact-host URL and SHA-256 hex value"), not as a network error. The command makes no requests. The exit code is still 65.
