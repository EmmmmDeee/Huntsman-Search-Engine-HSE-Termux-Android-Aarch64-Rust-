- A `docmeta FILE` command reads the metadata a document embeds in itself, keyless and offline: the uncompressed XMP metadata packet (the `<x:xmpmeta>` block PDFs, JPEG, TIFF and PNG carry) is flattened field by field as `prefix:Local` keys, and a PDF's `/Info` dictionary (Title, Author, Subject, Keywords, Creator, Producer, CreationDate, ModDate) is read too. Author, creator tool, create and modify timestamps, document and instance identifiers and title are kept as evidence on a document entity for the file, so nothing the metadata states is dropped, and when the XMP carries a GPS position it also becomes a coordinates entity — the same `lat,lon` the `geocode` command reverse-geocodes to an address. This complements `exif`, which decodes the binary EXIF block; `docmeta` reads the XMP packet and PDF dictionary instead. The scanner is bounds-checked and allocation-bounded, so a malformed or hostile file yields a clean result naming its format and size, never a panic.
