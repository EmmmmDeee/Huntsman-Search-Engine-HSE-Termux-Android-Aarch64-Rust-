- `apk FILE --json` and the offline APK-upload API now expose `analysis.sdk_signers` for v3/v3.1 signing-certificate claims scoped to each signer's declared Android SDK range. The document evidence carries `apk_sdk_signer_ranges_unverified` with scheme, signer index, min/max SDK and exact DER SHA-256. Invalid SDK copies, truncated signer records and ambiguous duplicate signing-scheme blocks cannot produce these observations. This is **structural metadata only**, not a verified certificate-rotation chain, signature authentication, device-specific installability or ownership attribution. Existing signer pivots and v2 digest checks are unchanged; no new dependencies or network requests.
