- The build script is removed. `build.rs` wrote an empty `hibp_embedded_key.txt` into Cargo's `OUT_DIR` that nothing ever read, and with it go the release workflow's step that required that file to be empty, the `HUNTSMAN_HIBP_NO_EMBED` variable that CI, the release workflow, the container build, the installer and the docs set for a script that read nothing, `tests/hibp_build.rs`, and the `hibp::key::EmbeddedSource` and `KeyOrigin::Embedded` stubs, which no production loader ever produced. The proof that a published binary holds no key is unchanged: `.github/scripts/scan-for-keys.sh` must report zero findings over the exact published files before anything is published. The four library modules with no caller (`path`, `method_actor`, `method_actors`, `wayback`; about 1,470 lines) left in #970; their last mentions leave `ARCHITECTURE.md` here, and the `wayback` search route that `plan` and `source-registry` list is a URL template in `source_registry` and stays. `tests/runtime_reachability.rs` now requires every module outside the runtime spine to be named by a `crate::` or `huntsman_recon::` path from the binary, a test, an example, xtask, a runtime module or a module one of those reaches, so a module that only its own doctests or another dead module names fails the test.
