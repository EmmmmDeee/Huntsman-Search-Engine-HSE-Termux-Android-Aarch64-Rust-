- `claim_coverage::CoverageRequirement::evaluate` admits no negative for a malformed requirement: a time window that ends before it starts, or a blank evidence class or query scope. Before, an inverted window could be "covered" by a point observation and close a negative obligation. A clean negative from a provider with a blank id no longer qualifies, while that provider's positive, failed or partial result still counts against the claim. No shipped command calls this module yet.
- `resolve::automatic_clusters` returns clusters in the same order whichever side of a match each uid was written on. `UnionFind::groups` now orders its sets by their smallest index, so its result depends only on what was joined, not on the order of the unions; the relation graph's identity clusters, which sorted the same way afterwards, are unchanged.
