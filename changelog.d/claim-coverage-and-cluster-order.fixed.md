- `claim_coverage::CoverageRequirement::evaluate` admits no negative for a malformed requirement or claim: a time window that ends before it starts, a blank evidence class or query scope, or a blank claim id. Before, an inverted window could be "covered" by a point observation and close a negative obligation. Open-ended and single-instant windows are unaffected. A clean negative from a provider with a blank id no longer qualifies and is reported as incomplete coverage, and that provider's positive, failed or partial result still blocks the negative. No shipped command calls this module yet.
- `resolve::automatic_clusters` returns clusters in the same order whichever side of a match each uid was written on. `UnionFind::groups` now orders its sets by their smallest index, so its result depends only on what was joined, not on the order of the unions; the relation graph's identity clusters, which sorted the same way afterwards, are unchanged. No shipped command calls `automatic_clusters` yet, so no output changes.
