- The tests now hold every lookup to the refusal and no-response contract. Each module of the ip, netblock, asn, domain, email, username, exposure and network lookups is chosen alone over a network that refuses every request, one that never answers, and one that answers every request with HTTP 500, through the same concurrent fan-out real lookups use. A refused request must end the lookup as a refusal (exit 77) naming the module, no response must end it as unavailable (exit 69) naming the module, and a source that answered with an error, or a module that asked nothing, must never read as a refusal. The modules that break the contract today are listed exactly, for each network: a module that newly breaks it fails the test, and so does a listed module that no longer breaks it, so the list can only shrink. The cases where a module asks nothing are listed exactly too, so a module that falls silent fails the test instead of passing unchecked. The ip and domain tests share one refusing test transport instead of keeping a copy each. Lookup output and exit statuses do not change.
