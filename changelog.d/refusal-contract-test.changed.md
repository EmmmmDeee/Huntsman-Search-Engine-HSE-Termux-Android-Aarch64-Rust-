- The tests now hold every lookup to the refusal and no-response contract. Each module of the ip, netblock, asn, domain, email, username, exposure and network lookups is chosen alone over a network that refuses every request, one that never answers, and one that answers every request with HTTP 500. A refused request must end the lookup as a refusal (exit 77) naming the module, no response must end it as unavailable (exit 69) naming the module, and a source that answered with an error must never read as a refusal. The lookups that do not keep the contract yet are on a pending list, and the test fails when an entry no longer breaks the contract, so the list can only shrink. The ip and domain tests share one refusing test transport instead of keeping a copy each. Lookup output and exit statuses do not change.
