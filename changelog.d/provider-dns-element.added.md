- The name servers a domain's RDAP/WHOIS registration lists are now surfaced as `PROVIDER_DNS` elements ("Name Server (DNS NS Records)") in the Spiderfoot element view, giving that catalogued element type its first producer. The RDAP lookup already records each name server; before this they survived only inside the raw registration record and never appeared as a typed element, so they were absent from Browse by type, the per-type summary, exports and correlations. Each listed server becomes one element; no extra network request is made.
