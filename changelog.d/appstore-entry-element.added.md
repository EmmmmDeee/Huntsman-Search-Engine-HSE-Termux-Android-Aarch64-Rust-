- An app found by the `apple_itunes` keyword lookup is now surfaced as an `APPSTORE_ENTRY` element in the Spiderfoot element view, giving that catalogued element type its first producer. The iTunes lookup already tags each app's URL as an App Store entry, so the element is typed from that tag rather than as a generic linked URL; its seller, bundle identifier, genre and release date stay on the element's raw evidence, so nothing is lost and no extra network request is made.
