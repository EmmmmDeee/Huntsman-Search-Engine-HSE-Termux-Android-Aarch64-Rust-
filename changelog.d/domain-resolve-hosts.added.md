- A domain lookup, and so a domain scan, `sf -s` and the web UI, now resolves every subdomain it finds, as Spiderfoot's `sfp_dnsresolve` does: each host's A and AAAA records over the same DoH resolvers, eight hosts at a time and up to 512. Each public address is an address entity that is the host's child in the element tree, every address (a private one too) is listed on the host so the resolution relation and the shared-hosting rule see it, and a host with neither record is tagged `unresolved` and exported as `INTERNET_NAME_UNRESOLVED` (`AFFILIATE_INTERNET_NAME_UNRESOLVED` outside the target). The `dnsresolve` outcome row counts hosts resolved, unresolved, unanswered and not asked. Before, a scan's subdomains were names only.
