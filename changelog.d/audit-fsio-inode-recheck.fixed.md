- Every bounded read re-checks the inode it opened, and the directive files go through `fsio`. `fsio::read_bounded` checked the path with `lstat` and the opened descriptor with `fstat`, but a descriptor is never a symlink, so a link planted between the two calls was followed; only the keys file, through `keys::read_private_file`, compared the device and inode of the two. That comparison is now one `fsio::same_inode` helper, and `read_bounded` makes it for every caller (`--keys FILE`, `investigate --file`, `scan --input-file`, the ledger, the session store, the run history and the rest), refusing a path that changed with `changed between the check and the open`; a symlink is still refused with `refusing symlink`. The run-history writes (the append and the torn-tail truncation) checked the path the same way and then opened it by name; they now compare the descriptor they opened with the `lstat` result too, and a history that does not exist yet is created exclusively, so a link planted after the check is never followed. `directive_lock` read the canonical file and its six mirrors with no bound, wrote each mirror with `fs::write` to a predictable `.tmp-<pid>` name, which followed a planted link, created a missing `.github/` with `create_dir_all`, which followed a symlinked one, and never flushed. Its reads and writes now go through `fsio::read_bounded` and `fsio::write_atomic` under a 1 MiB cap (`directive_lock::MAX_DIRECTIVE_BYTES`), so `huntsman-recon check` and `directive check|sync` refuse a symlinked or oversized mirror, `directive sync` refuses a symlinked mirror directory, each naming the path, and a written mirror is flushed before its rename; a missing `.github/` is still created. The locks are unit tests in `src/fsio.rs` (the inode helper, and a descriptor that is not the checked inode), `src/run_history.rs` (the same descriptor comparison before a write) and `src/directive_lock.rs` (the symlinked mirror and directory, the oversized mirror); each fails on the previous code, and a further test holds the created directory.
