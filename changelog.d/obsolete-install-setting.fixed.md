- When a private keys file contains the unsupported `HUNTSMAN_INSTALL_DIR` setting, `credential-status` now identifies it as an obsolete installer option instead of an API key, shows the supported `HUNTSMAN_INSTALL_ROOT` installer-only override, and names the non-destructive single-slot removal command. `doctor` supplies that exact manual command when this is the only unknown slot. No credentials are printed, no API quotas are spent, and `doctor --fix` does not silently change the file.
