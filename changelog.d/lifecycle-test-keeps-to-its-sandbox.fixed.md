- Running the test suite with `CARGO_TARGET_DIR` set no longer replaces the built `huntsman-recon` with a stub that prints nothing and exits 0. The lifecycle test that simulates an interrupted `cargo test` runs `scripts/lifecycle.sh` with a mock `cargo` whose build step writes that stub to `$CARGO_TARGET_DIR/debug/huntsman-recon`, and the script inherited the caller's target directory. Every CLI test that ran afterwards then saw exit 0 for refused input (for example `lookup_exit_status`). The test's sandbox now sets its own `CARGO_TARGET_DIR`.
