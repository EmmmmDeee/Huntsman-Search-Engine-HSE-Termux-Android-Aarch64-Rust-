- The passive-DNS record set the keyless `mnemonic` lookup collects for a queried domain or IP is now surfaced as a `RAW_DNS_RECORDS` element in the Spiderfoot element view, giving that catalogued element type its first producer. The lookup already records every record line on the host it queried; before this they survived only inside that host's raw evidence and never appeared as a typed element, so they were absent from Browse by type, the per-type summary, exports and correlations. The dump is emitted whole as one element — it is a single raw record set by design, not a re-splittable list — and is gated on the genuine `mnemonic` source and a host entity kind, so a same-named field from another source or on another entity kind cannot forge one. No extra network request is made.
