- JSON printed to the terminal no longer passes DEL, the C1 controls, the line and paragraph separators or the bidirectional controls through unchanged. `scans show --json`, `scans` listings, the `lookup` and `meta` and `radar` JSON output, and `lookup` discovery printed a value from a remote source as its raw characters, so a crafted record could drive the terminal or reorder the text beside it. Those characters are now written as `\uXXXX`, which every JSON reader decodes to the same value, and the Spiderfoot-compatible JSON already did this. The escaper is one function in `textnorm`, shared with that writer, and it changes no byte of ordinary output.
