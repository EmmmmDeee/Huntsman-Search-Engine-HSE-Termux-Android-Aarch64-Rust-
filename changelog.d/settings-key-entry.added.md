- The web UI's Settings saves a provider key: a keyed module's **Set key** writes it into `~/.huntsman.env`, the file every lookup reads, so the next lookup uses it without restarting `serve`, and **Remove** takes it out. The key travels only in a form body, is never shown again and no answer repeats it; the file is rewritten whole at mode 600, every other line left as it was. `GET /api/settings/keys` lists every catalogue slot with whether it is set and saved, and `POST /api/settings/keys` saves one, behind the lookup's guards.
