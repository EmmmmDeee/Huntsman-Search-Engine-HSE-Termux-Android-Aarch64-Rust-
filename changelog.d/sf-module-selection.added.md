- A saved scan can ask only the modules chosen, as Spiderfoot's By Module scan does: `scans run -m MODULE[,MODULE...]`, `sf -m` and `POST /api/scans?modules=` take Huntsman's module names or Spiderfoot's (`sfp_whois` stands for every module that does its work). A module not chosen sends nothing and leaves no outcome, a lookup that asks none of them is skipped with a log line, a target none of them looks up is refused before the scan starts, and offline modules always run. `/api/settings` names the lookups that ask each module, and a scan's `honoured.modules` is now `true`. The module registry gains OathNet, WiGLE and the offline OUI vendor table, which lookups already asked.
