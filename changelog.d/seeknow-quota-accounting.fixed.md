- SeekNow quota is now accounted from what the provider reports. The `x-ratelimit-limit`, `x-ratelimit-remaining` and `x-ratelimit-reset` headers on each search response were parsed but never kept. Each observation receipt now records them, and the `seeknow` command prints them on its source lines. An adaptive search no longer sends the 2-credit stealer request after a zero result whose response said no requests remain, so the request is neither wasted nor refused. A response without quota headers is never read as exhausted, and receipts saved before this change still load.
