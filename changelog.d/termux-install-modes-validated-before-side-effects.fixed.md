- The rootless Termux installer validates `HUNTSMAN_FROM_SOURCE` and `HUNTSMAN_REQUIRE_PREBUILT` as explicit `0`/`1` modes, rejecting unknown values and conflicting requests before touching persistent state, obtaining an install lock, making network requests or running `pkg`. Previously an unknown source-build setting could be silently ignored. Existing successful installation paths and the legacy `hse` handoff remain unchanged. The root-installer fixture covers invalid source-only, prebuilt-only and conflicting mode settings while asserting the accepted binary, history, state and network are untouched. README and installation guidance now distinguish current `main-<sha7>` releases from the old stable legacy release and document source/prebuilt mode selection.
