- A private write removes the temp file a killed earlier private write left beside the same file, once that writer process has exited and the file is ten minutes old. Such a file holds a full copy of the body being written (keys, sessions, ledgers), so an interrupted save no longer keeps that copy on disk indefinitely. The copy is removed by the next private write to that same file that comes at least ten minutes after the kill. Files that are not private, and writes on platforms other than Linux and Android, are not swept.
