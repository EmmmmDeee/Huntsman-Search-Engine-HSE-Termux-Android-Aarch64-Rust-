- The ISP or hosting organisation a host sits behind is now surfaced as a `PROVIDER_HOSTING` element in the Spiderfoot element view, giving that catalogued element type its first producer. The IP-reputation and geolocation lookups already record it as the `isp` attribute (the keyless `pulsedive` lookup, and `ipqs`, `shodan` and `abuseipdb` when their keys are configured), from the IP's registry, on the IP or the domain that resolved to it; before this it survived only inside that entity's raw evidence and never appeared as a typed element, so it was absent from Browse by type, the per-type summary, exports and correlations. The element is gated on that set of genuine sources, so a same-named attribute from elsewhere cannot forge it. No extra network request is made.
