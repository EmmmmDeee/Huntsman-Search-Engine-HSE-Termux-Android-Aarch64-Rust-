- Every keyed source a lookup asks whose key is not set now leaves a `not_configured` row in the Sources table, with the detail `no operator key configured; no request made`, as the breach and exposure legs already did: Numverify on a phone lookup, SeekNow on an email or people lookup, and every indicator source (Shodan, IPQS, Hunter, SecurityTrails and the rest) on the lookups that would ask it. Before, these legs were skipped silently, so a scan on a phone with no keys set showed `not_configured: 0` and gave no sign that carrier validation or the keyed intelligence sources were never queried.
