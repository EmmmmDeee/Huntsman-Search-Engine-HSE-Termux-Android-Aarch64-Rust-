- The `username` lookup now queries English Wikipedia's keyless MediaWiki `usercontribs` API for the handle's recent public page edits (`wikipedia` source leg). Each edit becomes a URL to that exact revision, tagged as a Wikipedia page edit so it is typed `WIKIPEDIA_PAGE_EDIT` in the Spiderfoot element view, with the editor, page title, revision id, timestamp and edit summary kept as evidence; the account's contributions page is kept as an anchor. The recent window is bounded, the leg runs keyless and makes no request for an empty or over-long selector, and a rate-limited or malformed response degrades to a typed source outcome rather than failing the lookup.
