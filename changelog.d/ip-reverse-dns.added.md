- An IP lookup, and so an IP scan, `sf -s` and the web UI, now asks the address's own reverse zone for its PTR records over the DoH resolvers, as Spiderfoot's `sfp_dnsresolve` reverse-resolves every address. Every record is listed on the address as published; each name in canonical form is a domain pivot tagged `ptr`, the address's own `INTERNET_NAME` in a saved scan rather than a co-hosted site. Its `dnsresolve` row is a validated zero when the reverse zone has no record. Before, reverse names came only from third parties (InternetDB, IPinfo).
