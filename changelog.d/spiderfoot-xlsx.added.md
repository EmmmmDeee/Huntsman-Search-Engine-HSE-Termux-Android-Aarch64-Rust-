- Export saved scans as Excel workbooks, as Spiderfoot does: `scans export ID -f xlsx` (or `excel`) and `GET /api/scans/ID/export?format=xlsx` write Spiderfoot's `buildExcel` layout, a sheet per data type in name order with `Updated, Module, Source, F/P, Data`, and `scans correlations ID -f xlsx` a sheet per rule. The workbook is written by `xlsx`, a dependency-free Office Open XML writer: every cell is text, so a value is never run as a formula and needs no guard; a character XML cannot hold is kept as Excel's `_xHHHH_` escape; and a value longer than Excel's 32,767-character cell carries on, whole, after the row's last column. Several scans now export together as CSV, TSV or Excel too, with Spiderfoot's `Scan Name` column first (`scaneventresultexportmulti`), not only as JSON. The scan API's answers are bytes (`ApiResponse::text` reads one as text), and `serve` sends a binary export with its exact length.
