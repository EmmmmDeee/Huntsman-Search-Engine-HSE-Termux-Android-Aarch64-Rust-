- `query --all QUERY...`, `query --adaptive --all QUERY...` and `research --all TERM...` ask 13 keyless public search engines instead of the default Bing, Brave and Mojeek: DuckDuckGo, Google, Yahoo, Ecosia, Startpage, Yandex, Yep, Lilo, You.com and Wiby join them. Qwant, Swisscows and Marginalia are not asked: fetched this way, their result pages hold only their own site links, which would read as results. One 110-second budget covers the whole run, each request is capped at 6 seconds or what is left of the budget, and an engine the budget leaves out is reported as not queried, never as a zero result. Every other command, and the web UI, keep the three default engines.
- DuckDuckGo, Google and Yahoo result redirects are decoded offline, like Bing click redirects, and never followed. A result on another engine's domain, such as `finance.yahoo.com` from Bing, stays a result.
- `query --adaptive` no longer asks an engine again in its later rounds once the engine refused the first round with a block page, a rate limit or an authentication wall; each later round keeps a row saying it was not queried.
- `sources` and the offline route planner add one search link per default keyless engine for a person, organisation, email, handle, domain, IP address or ABN/ACN, built exactly as `query` builds its requests, with a space encoded as `%20`. A credential, API key, device identifier or residual text never gets one.
- The anonymous search-page cache keeps at most 64 pages and never a page over 512 KiB, so it holds at most 32 MiB of pages on a phone.
