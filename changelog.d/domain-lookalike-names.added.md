- `domain` tags each other registered domain it finds (a name server, mail exchanger, certificate
  name or co-hosted site) whose name is one edit or one look-alike character from the looked-up
  domain's, such as `githuh.com` beside `github.com`, as `lookalike`. Spiderfoot views of the
  lookup report it as `SIMILARDOMAIN` instead of an affiliate. The tag says the names are
  confusable, never who holds either.
