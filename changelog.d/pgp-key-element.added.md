- A published OpenPGP key found by the `openpgp_keys` lookup is now surfaced as its own `PGP_KEY` element in the Spiderfoot element view, giving that catalogued element type its first producer. The element carries the key's fingerprint and a link to fetch the key itself, and the whole key record (fingerprint, fetch URL and creation time) is preserved in the element's raw evidence, so nothing is lost. The element is produced from evidence the lookup already collected, so no extra network request is made.
