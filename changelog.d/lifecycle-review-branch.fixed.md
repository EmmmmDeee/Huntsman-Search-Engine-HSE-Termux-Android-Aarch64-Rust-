- Termux lifecycle `sync` and `all` no longer publish directly to unprotected `main`, which conflicts with the exact-main merged-PR CI origin gate. After the existing build/check/test and verified-tree checks, sync now pushes the exact verified commit to an idempotent `lifecycle/<full-sha>` review branch and records `pending` until a PR is reviewed and merged. The original `main` remains unchanged; secret guards and interruption checks remain enforced. A local-bare-remote regression asserts ordinary work is staged without changing main and clean retries reuse the review branch.\n
