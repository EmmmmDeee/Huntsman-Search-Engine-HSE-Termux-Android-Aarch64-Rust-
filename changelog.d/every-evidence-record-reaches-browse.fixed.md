- A second record from one source about one entity is no longer dropped from a saved scan's elements. Elements are keyed, as Spiderfoot keys events, by type, data, source element and module, and a second record with the same key was skipped whole, so its summary, attributes, time and provenance were readable nowhere on the page or in an export although `results.json` kept them. The element now keeps every record (its raw becomes a list when a second arrives, as the target element's already is) and is created when the earliest was recorded.
