- Unix time is read in one place. Twenty-five call sites took the epoch offset from `SystemTime` by hand, four modules each kept a private `now_unix` helper, and `entity::unix_now` was one more copy. They now ask `clock::unix_now`, `unix_now_millis`, `unix_now_nanos`, `unix_subsec_nanos` or `unix_secs_of` (a file's modification time). Every reading is unchanged: a clock before the epoch still gives 0, and a file time before the epoch still gives no seconds. A boundary test holds production code outside `src/clock.rs` to asking that module for the time.
