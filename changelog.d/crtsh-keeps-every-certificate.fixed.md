- A `domain` lookup (and `network crtsh`) keeps every certificate crt.sh logs for a name. Each name's evidence came from the first certificate that listed it; every later certificate for the same name was dropped, and no certificate's crt.sh id, issuing CA id or log time was kept. Each name's evidence now also holds, across every certificate that names it: `certificates` (how many), `cert_ids` (each certificate whole at `https://crt.sh/?id=…`), `cert_serials`, `issuers`, `issuer_ca_ids`, `common_names`, `first_not_before`, `last_not_after`, `first_logged` and `last_logged`. An enterprise issuer organisation keeps the same across the certificates it signed, and every name on them in `signed_names`. A certificate that lists a name twice counts once.
