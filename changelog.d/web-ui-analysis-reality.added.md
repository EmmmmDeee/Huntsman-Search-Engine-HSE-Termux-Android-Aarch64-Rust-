- The scan view gains an Analysis tab and, behind each data element that shows an entity, a Source attribution button. Both reach routes the server already answered but the page had no control for, which a phone browser cannot reach by typing a URL: the offline analysis of the saved entities (`/api/scans/{id}/analyze`: every count, every stated limitation and the full report) and the per-entity assessment (`/api/scans/{id}/reality`: which source families asserted each attribute and with what status, competing values, and the server's own limitation statements). A refusal while the scan runs or once an element is flagged a false positive is shown verbatim.
