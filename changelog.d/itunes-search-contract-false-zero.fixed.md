- The keyless iTunes App Store search collector no longer labels malformed or contradictory `resultCount`/`results` response envelopes as a confirmed zero. A missing or inconsistent envelope is `schema_drift`; a nonempty set with no usable HTTPS app page is `inconclusive`. Only an explicit matching `resultCount: 0, results: []` returns `valid_zero`. All outcomes retain their HTTP status, while successful app URL extraction and existing CLI/JSON contracts remain unchanged.
