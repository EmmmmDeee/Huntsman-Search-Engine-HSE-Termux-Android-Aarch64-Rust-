- The main-channel pre-release no longer lags behind `main` for good when `main` moves on during a build. A build is skipped only when a newer `main` commit has a queued, running or successful release build of its own, so a push that touches no release path (docs, tests, changelog fragments) or a newer build that failed no longer strands the prebuilt that the installer picks. The decision is one function inlined in the head check and the publish step and is exercised offline against a fake `gh` (`tests/release_ci.rs`).
