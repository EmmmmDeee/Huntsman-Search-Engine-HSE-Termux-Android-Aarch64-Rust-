- `exif` and `docmeta` (and the web UI's Inspect, which runs both) no longer cut metadata silently. A text value longer than the 8 KiB display bound, or an EXIF tag read short of the length it declares, now ends with ` … (N bytes, first M shown)`; a long number array or byte value counts how many the tag declares, not only how many were read; `docmeta` counts the fields a file holds past the 512-field bound (`metadata_fields_omitted`, and the summary says `N field(s) kept and M more not kept`) and the distinct values of a repeated property that no longer fit (`metadata_values_omitted`), and reads a PDF string in full so the marker names its true length.
