- `HUNTSMAN_HOME` given to the installer now reaches the web UI service and the `huntsman` command. The installer wrote the chosen state directory into the service's run script only as the path of `serve.bind`, so the service process, with no `HUNTSMAN_HOME` of its own, kept its scans under `~/.huntsman` while reading a `serve.bind` elsewhere, and `huntsman start` from a shell without the export wrote `serve.bind` where the service never looked, leaving runit retrying a taken port. The run script now exports `HUNTSMAN_HOME`, `huntsman` reads the state directory from the run script when its shell has none and exports it to every command it passes on, and `installed-revision` records `state_dir`.
