- `apk FILE` now names the third-party SDKs an app bundles — the analytics, advertising, attribution, crash-reporting and push trackers (Exodus-Privacy style) — from the Java package prefixes its DEX code references, in the same string-table pass that already extracts code URLs, so it costs no extra read. Each match is reported as `Name (category)` on the document evidence (`apk_bundled_sdks`) and in the JSON (`analysis.code.trackers`). The signature list is a curated, auditable set of well-documented package prefixes matched longest-first; a match means the SDK's code is present, a privacy and attribution signal, never proof the app uses it at runtime.
