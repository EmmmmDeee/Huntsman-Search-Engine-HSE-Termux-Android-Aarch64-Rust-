- A Bitcoin address's on-chain balance from the keyless `blockchain` (blockchain.info) lookup is now surfaced as a `BITCOIN_BALANCE` element in the Spiderfoot element view, giving that catalogued element type its first producer. The lookup already records the balance; before this it survived only inside the address's raw evidence and never appeared as a typed element, so it was absent from Browse by type, the per-type summary, exports and correlations. The satoshi figure and received/sent totals stay on the element's raw evidence, and a zero balance is kept as a real finding. No extra network request is made.
