- `/api/health` now includes the running server's embedded 40-character `build_sha` (or `unknown`). `huntsman-recon doctor serve` compares it with the probing CLI's immutable build SHA, reporting `degraded` and the explicit mismatch/restart action if a previous binary still owns the port, even when the human-readable version and web page are unchanged. An older server missing the SHA also fails verification when the CLI has a known SHA. Locally built binaries with `unknown` cannot prove revision parity; the probe still performs its independent page, policy and API checks. No provider access, new dependency, persistent data or new listening interface is introduced.
