- Restore a rootless Termux/Android Wi-Fi radar acquisition path: `huntsman-recon radar wifi [--json] [--file TERMUX_SCAN_JSON]`. The Rust adapter reads the standard Termux:API cached scan JSON through a bounded, timed process invocation or an offline replay file, emitting typed RF sightings with BSSID, SSID, RSSI, frequency, optional capability strings and Android boot-relative scan timestamps. It calculates age using /proc/uptime when available, distinguishes stale/unknown observations, and refuses to report a cached scan as an actively triggered scan, a geolocated device, or a clean zero when Android supplied no results. The CLI is registered in help and the reachable module catalogue; deterministic CLI and parser regressions cover errors, overlong payloads, missing input, stale timestamps and absence of made-up positions. The Android Termux:API companion app and its location permissions are prerequisites for real handset collection.
