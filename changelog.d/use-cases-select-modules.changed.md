- The Footprint and Investigate use cases on New Scan, `scans run -u` and `sf -u` now choose modules, as the page has described them: Footprint runs every source but the threat, blocklist and reputation ones, Investigate runs those with the basic footprint (names and addresses, infrastructure, breach exposure, the target's own data) and without the social, search, people and corporate sources, and neither adds a module to those chosen by name. Before, both ran exactly what All runs and spent the same keyed quotas, with only the "Use case applied" row of Scan Settings admitting it; that row now reads as honoured. A use case that leaves a target's lookup nothing to ask is refused by name before the scan is saved. Passive is unchanged: it skips an email's keyed breach lookup and follows no email it finds.
