- The names a scan's Sources table shows are now names New Scan and `scans run` accept and explain. A leg's label chooses its module (`modules=hibp_account` runs HIBP, `wigle_bluetooth` runs WiGLE, `asic_persons.banned` runs the ASIC persons register) instead of being refused as a module nobody asks, and `/api/settings` lists which lookups ask a module under such a label. The offline modules every lookup of a kind runs over the target itself (phone_intl and phone_au for a phone number, oui for a BSSID, email_parse and username_variants) are reported as `offline_in` and the By Module list says "Always runs offline in: Phone number" for them, where it used to say "no scan lookup asks it" about rows the Sources table had just shown.
