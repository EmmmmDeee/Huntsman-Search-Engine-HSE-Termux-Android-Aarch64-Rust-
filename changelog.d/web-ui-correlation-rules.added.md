- The serve page's Correlations section shows each correlation's rule, where the rule came from (`huntsman`, `spiderfoot` or a file in `~/.huntsman/correlations`) and the rule as written. It re-runs every rule over the saved elements (after false positives are marked) and exports the correlations as CSV, TSV or JSON. Settings lists every correlation rule a scan runs, each with its risk, origin and logic. `serve` now opens saved scans with the operator's own rules, as `scans` does, and names on stderr any rule file it cannot read.
