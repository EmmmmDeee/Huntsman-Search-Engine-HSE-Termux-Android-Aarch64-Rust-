- Changing `HIBP_API_KEY` in the environment no longer rebuilds the crate and every test binary. The build script registered the runtime key variable, with `HSE_RELEASE`, `HUNTSMAN_HIBP_NO_EMBED` and `HUNTSMAN_BUILD_SHA`, as a rebuild trigger although it read none of them, so a `cargo test` after exporting or changing the key recompiled everything. `build-sha` and `diagnostics` still pick up a changed `HUNTSMAN_BUILD_SHA`, because `option_env!` tracks it through Cargo's dependency info without a build script.
