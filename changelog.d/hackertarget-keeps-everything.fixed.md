- A `domain` or `ip` lookup keeps every host HackerTarget finds. `hackertarget::decode` kept at most 25 hosts and 25 addresses and tagged the rest `truncated`, never kept which address each host resolved to, and counted a host again each time it reappeared after the first 25. Every distinct host and address is now kept and counted once, every `host address` pair is kept in `host_addresses`, and every line of the answer is kept as a JSON list in `raw_answer`.
