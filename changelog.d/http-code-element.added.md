- The HTTP status a host's web server returned, from the keyless `pulsedive` lookup, is now surfaced as an `HTTP_CODE` element in the Spiderfoot element view, giving that catalogued element type its first producer. The lookup already records the status code on the IP or domain it probed; before this it survived only inside that entity's raw evidence and never appeared as a typed element, so it was absent from Browse by type, the per-type summary, exports and correlations. The element is gated on the genuine `pulsedive` source, the host entity kind, and the value being a real 1xx-5xx status, so a same-named attribute from another source or a malformed value cannot forge it. No extra network request is made.
