- `geocode PLACE|LAT,LON`: keyless forward and reverse geocoding over OpenStreetMap's Nominatim. A place name or street address becomes the coordinates and full address of each match; a `lat,lon` point becomes the address at that spot. Each match is a coordinates entity for its point and an address entity for its written address, with every field Nominatim returns -- each separate address component included -- kept as evidence, so no part of the answer is dropped.
