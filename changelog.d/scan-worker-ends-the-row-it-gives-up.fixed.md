- A scan whose worker stops without recording an outcome is now marked `ERROR_FAILED`. When a scan's status could not be saved, its worker gave up and left the row active under the server, with nothing left to finish it. The row could then be neither stopped nor deleted, and continuous scanning never rescanned its target, until the server restarted.
- A repeated lookup request no longer joins a scan the server has stopped running, or one whose last status could not be saved. Such a request used to wait on a worker that never came, or got back that save error. It now starts a new scan. A request made while the identical scan is being created joins that scan instead of starting a second one.
