- `phone` records a number's ITU calling code and full national number. Before, a Caribbean
  number, and once Canada was listed a Canadian one, was recorded with its area code as the
  calling code: `country_code 1416` and `national_number 5550199` for `+1 416 555 0199`. A
  Kazakh number was recorded as `77`. It is now `1` and `4165550199`, and `7` for Kazakhstan.
