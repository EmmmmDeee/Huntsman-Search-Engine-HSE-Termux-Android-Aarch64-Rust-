- The intelligence report that `plan`, `/api/analyze` and `scan --recurse` build is about twice as fast, with the same output. Exposure scoring and the timeline used to run three times and twice per report; each now runs once and is shared by the profiles and leads built from it. Each entity's corroborating sources are counted once instead of up to four times. The community count reuses the bridges the report has already found, instead of searching again and building member lists only to count them. Over 4,000 entities the median build fell from 49.3 ms to 22.1 ms. Library callers: `compute_exposure` returns the findings directly (the unused `ExposureIndex` wrapper and its `total_score` are gone), `rank_leads` and `build_profiles` take the exposures, and `build_profiles` also takes the timeline. `community::detect_communities` and `Community` are replaced by `community_count(graph, bridges)`.
