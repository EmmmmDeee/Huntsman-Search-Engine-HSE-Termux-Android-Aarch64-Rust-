- `apk FILE` now grades an app's security posture from its decoded manifest: a ranked set of flags (`apk_risk_highest`, `apk_risk_flags` on the document evidence; `analysis.risk_flags` in the JSON) covering a debuggable build (HIGH), cleartext-traffic and testOnly (MEDIUM), adb-extractable backup, a shared user id and exported components (LOW), and each sensitive permission the app requests — SMS, contacts, call log, precise/background location, microphone, camera, phone identifiers, all-package visibility, overlay and accessibility among them (INFO). Each flag is what the manifest declares, graded by how much it widens the attack surface or what it can collect, never a claim about runtime behaviour.
