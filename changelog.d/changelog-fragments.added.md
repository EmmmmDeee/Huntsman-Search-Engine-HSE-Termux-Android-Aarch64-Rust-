- Changelog entries are fragments: a change adds `changelog.d/<slug>.<section>.md` instead of a line in this file, so pull requests stop conflicting on the one line every one of them added at the top of a section. `cargo run --locked -p xtask -- changelog check` validates the fragments in every gate mode, `render` prints the assembled changelog, and `assemble` moves the fragments into the `[Unreleased]` sections when a version heading is cut (`xtask/src/changelog.rs`, `changelog.d/README.md`).
