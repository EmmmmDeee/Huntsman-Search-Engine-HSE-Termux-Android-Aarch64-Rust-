- Saved scans follow what they find. `scans run TARGET --depth N` (and the scan API's `depth=N`) looks up each email, username, domain, phone, IP address and BSSID a lookup finds, N hops past the target, through the same bounded crawl as `scan --recurse` (`recursion::run_targets`, now with an operator stop that ends the crawl as `cancelled` before the next lookup). Every element names the element of the lookup that found it (`sf_elements::elements_with_lineage`), so a deeper scan's elements, graph and GEXF export are its discovery tree, the way Spiderfoot's events chain to their source events. The scan keeps the crawl's lineage and termination reason, and `/api/scans/ID` returns both. Depth 0, the default, runs the target's lookup only, as before; an email's breach lookup is still never asked twice.
