- `scan --recurse` now feeds the crawl's own discovery lineage into the shared analysis graph, so the metrics, capability gaps and pivot ranking reflect the cross-kind pivots the crawl actually walked (e-mail → phone → username → domain → IP). Previously the analysis was rebuilt from entity content alone, so a crawl whose entities shared no handle, address or registrant reported the very entities it had pivoted on as unlinked orphans, ranked no pivot, and understated its own structure.
