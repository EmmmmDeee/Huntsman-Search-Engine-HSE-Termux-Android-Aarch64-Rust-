- The web UI starts a scan from what a scan found. Every element whose value is itself a target (a host or domain, including affiliates, co-hosted sites and similar domains, an IP address, an email, a phone number, a username, a human name or a BSSID) offers New Scan of this in its raw record, in Browse, search results and correlations alike. It fills New Scan with the value, detects its type, and keeps the use case and depth of the scan that found it, to change before it runs. A test keeps the offered types to Spiderfoot types and requires every type a scan target can be, and every entity a deeper scan follows, among them.
