- The web server a host advertises in its HTTP `Server` banner, from the keyless `pulsedive` lookup, is now surfaced as a `WEBSERVER_BANNER` element in the Spiderfoot element view, giving that catalogued element type its first producer. The lookup already records the banner on the IP or domain it observed; before this it survived only inside that entity's raw evidence and never appeared as a typed element, so it was absent from Browse by type, the per-type summary, exports and correlations. The element is gated on the genuine `pulsedive` source and the host entity kind, so a same-named attribute from another source cannot forge it. No extra network request is made.
