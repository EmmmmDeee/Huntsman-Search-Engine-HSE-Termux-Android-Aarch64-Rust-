- Every workflow that builds or tests the crate runs on one pinned stable release, Rust 1.99, instead of the floating `stable` channel. Clippy 1.99 turned `main` red on a tree the gate had passed on 1.97, with no change to the code, so now a new release's lints wait for a deliberate bump. #967 pinned `ci.yml` and `release.yml`; this change pins the four `issue-fix.yml` jobs too, and `tests/ci_toolchains.rs` holds the pin for all four gated workflows (`ci`, `release`, `issue-fix`, `dual-pass`): it fails on any of them naming `stable`, `beta` or `nightly`, ties the MSRV leg to `gate msrv` and the pinned leg to `gate full`, and checks the pin is newer than the MSRV. `audit.yml` keeps the newest stable, since it only installs `cargo-audit` and reads the lockfile.
