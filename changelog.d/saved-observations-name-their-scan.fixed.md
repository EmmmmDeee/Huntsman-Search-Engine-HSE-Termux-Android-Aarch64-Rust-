- Every observation a saved scan keeps now names that scan. Each lookup front-end mints a private scan id for the entities it builds, and saved scans stored it unchanged, so the `scan_id` in an element's raw record, in an evidence record's provenance and in every observation a merge kept matched no scan in the list, and the chain from a finding to the scan that observed it stopped there. Saving a scan now stamps the saved scan's id on every entity and observation, and an observation a merge kept that differed from the record's own only by that private id is kept once.
