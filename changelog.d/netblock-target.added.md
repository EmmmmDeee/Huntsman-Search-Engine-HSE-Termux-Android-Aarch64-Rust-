- `netblock CIDR` looks up one public IPv4 or IPv6 address block, Spiderfoot's `NETBLOCK_OWNER` (`NETBLOCKV6_OWNER`) target, and `scan`, `sf -s 1.2.3.0/24`, saved scans and the web UI's New Scan (a target type of its own, and New Scan of any block a scan found) take one too. It reads the block's RDAP registration (`NETBLOCK_WHOIS`, holder, contacts), the RIPEstat prefix and origin AS covering it, and, as Spiderfoot's `sfp_dnsresolve` sweeps a netblock target, the PTR records of every address in a block of at most 256 addresses (a /24 or an IPv6 /120): each named address is an `IP_ADDRESS` found from the block and each name that address's `INTERNET_NAME`. A larger block's `dnsresolve` row says it was not swept; a private or documentation block is refused before any request. Before, `sf -s` refused a netblock as "not available yet".
