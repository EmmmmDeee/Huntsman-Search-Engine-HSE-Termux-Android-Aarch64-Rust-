- A keyed HIBP call no longer sleeps out an earlier 429. After HIBP answered one seed of a batch or recursive scan with `retry-after: 3600`, the next keyed HIBP call blocked silently for about an hour before sending. While the server's pause has more than `max_retry_after` (60 s) left, the call now returns `hibp: rate limited (HTTP 429)` at once with the time remaining, and the exposure outcome is rate-limited. In both cases nothing is sent before the server's time.
- A 429 whose `retry-after` is beyond the clock's range is a rate limit, not `hibp: could not decode response: retry delay exceeds clock range` (an exposure schema-drift outcome). The shared pause is held for at most one hour, the bound every other provider pause uses.
- `dehashed search --email` refuses a local part that starts or ends with `.` or contains `..` (exit 65), as the other email checks do, instead of sending a paid search for a value that cannot be an unquoted address. Domain labels use the shared label rule, which accepts the same set.
