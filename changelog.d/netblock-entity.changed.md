- An address block is an entity of its own kind, `netblock`, written as its first address and prefix (`192.0.2.7/24` is `192.0.2.0/24`), so a block any source reports merges with the same block from another, links what was found in it in a saved scan, and maps to Spiderfoot's `NETBLOCK_MEMBER` (`NETBLOCKV6_MEMBER`). CIDR parsing, containment and address listing now live in one place shared by SPF analysis, the RDAP bootstrap and the netblock lookup, and the resolver fan-out that `domain` uses to resolve subdomains is the one the netblock sweep uses.
