- The web search response cache stays useful in a long-running `serve`. `circuit::ResponseCache` refused every new key once it held its 256 entries, so after 256 distinct engine queries no later query was cached and every repeat went back to the engine; it now evicts the least recently used entry (reads and writes both count as use) and keeps the latest 256. `circuit::tests::a_full_response_cache_evicts_the_least_recently_used_entry` pins it.
