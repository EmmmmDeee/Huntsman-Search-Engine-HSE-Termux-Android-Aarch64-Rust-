- The web UI starts and reads recursive scans. New Scan has a recursion depth, sent as the scan API's `depth`, so a scan follows what it finds as many hops as the operator asks; the scan header names the depth. Scan Settings shows the depth, whether it was applied, why the scan stopped following what it found (`fixed_point`, `max_depth`, `resource_limit`, `cancelled` and the rest, each in words), and a Discovery Tree: every lookup the scan ran, by hop, with every entity it found, paged 200 rows at a time so nothing is cut. Clone, as in Spiderfoot, fills New Scan from a scan's name, target, lookup, use case, data types and depth to change before it runs.
