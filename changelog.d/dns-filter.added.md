- `domain` asks the eight public filtering resolvers Spiderfoot asks (AdGuard, CleanBrowsing, Cloudflare, Comodo, DNS for Family, OpenDNS, Quad9, Yandex) whether they block the domain, over wire-form DNS-over-HTTPS, or UDP to the filter's own servers for Comodo, Quad9, DNS for Family and Yandex, whose DoH needs HTTP/2. Each block is kept with its filter, resolver, answer, records and any extended DNS error, and is `BLACKLISTED_INTERNET_NAME` (and `MALICIOUS_INTERNET_NAME` for a threat filter) in a saved scan. Each filter is checked against a name it is known to block first, which catches a network that answers port 53 itself and AdGuard's and DNS for Family's current `0.0.0.0` block answer that Spiderfoot misses. `Transport::exchange_udp` is the one UDP path, egress-guarded.
