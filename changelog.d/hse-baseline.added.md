- `scripts/hse-baseline.sh` is a bounded, read-only baseline for the Termux (aarch64, no-root) upgrade pass: it clones the repository, cuts a local-only branch off `origin/main`, runs `cargo fmt --check`, `cargo check`, `cargo clippy -D warnings` and the test suite over the whole workspace with `--locked`, and always leaves `$WORK/reports/<stamp>/SUMMARY.txt` — even when a run aborts early. It never pushes, merges, commits, installs the app, or deploys; `tests/hse_baseline.rs` locks that read-only contract so a later edit cannot quietly turn the diagnostic into a mutation. `SKIP_TESTS=1` runs the checks without the tests and `RUN_RELEASE=1` adds the release build; `REF`, `WORK`, `JOBS` and `REPO_URL` are overridable.
