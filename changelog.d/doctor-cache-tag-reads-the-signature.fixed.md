- `huntsman-recon doctor` reads a build cache's `CACHEDIR.TAG` only as far as its signature. It read the whole file into memory before comparing the first 43 bytes, and it followed symlinks, so a tag file of any size could exhaust memory, and a symlink to `/dev/zero` never finished. The check now reads at most the signature's length, and it returns the same answer for every ordinary tag file. A file whose first bytes are the signature but which holds bytes that are not UTF-8 further on is now recognised, where before the whole-file UTF-8 read refused it. Cargo writes the signature as the first line of ASCII text, so no real cache changes its answer.
